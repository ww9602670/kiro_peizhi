## 问题汇总

### 问题1: 空列表时不渲染列表容器元素

**影响页面**:
- 账号管理页面
- 策略管理页面
- 投注记录页面
- 告警页面

**问题描述**:
当列表为空时，前端可能不渲染列表容器元素（如 `<table>` 或 `.list-container`），导致测试无法找到这些元素。

**当前状态**: 
- 不影响用户使用
- 不影响测试通过
- 仅影响测试验证的完整性

**建议处理**:
1. **前端改进**（可选）: 即使列表为空也渲染容器元素，显示"暂无数据"提示
2. **测试改进**（推荐）: 更新测试选择器，使用更通用的页面容器选择器
3. **文档记录**（当前）: 记录此行为，后续优化

**优先级**: 低（不影响功能）

## SPA导航问题记录

### 问题描述

前端是单页应用(SPA)，使用客户端路由，导航时URL不会改变。这导致以下测试方法不适用：

```python
# ❌ 不适用于SPA
await page.wait_for_url("**/accounts", timeout=5000)
```

### 实际行为

- 点击导航菜单后，页面内容会切换
- URL保持不变（始终是 http://localhost:5173/login）
- 页面切换通过React状态管理实现

### 测试策略

当前测试使用以下策略验证页面切换：

```python
# ✅ 适用于SPA
await page.click('text=账号')
await page.wait_for_timeout(1000)  # 等待页面切换动画
# 验证页面标题或特征元素
title = await page.query_selector('h1, .page-title')
```

### 后续优化建议

1. **使用内容等待**:
   ```python
   await page.click('text=账号')
   await page.wait_for_selector('h1:has-text("博彩账号")', timeout=5000)
   ```

2. **使用Playwright的locator API**:
   ```python
   await page.locator('text=账号').click()
   await expect(page.locator('h1')).to_have_text('博彩账号')
   ```

3. **监听状态变化**:
   ```python
   # 监听React状态变化或DOM变化
   await page.wait_for_function('document.querySelector("h1").textContent === "博彩账号"')
   ```

**优先级**: 中（已记录，后续优化）
