# 项目上下文

本项目当前有旧版 BetDesktop UI 和新版轻量对冲控制台两条路径。新版轻量控制台的目标是保留已经验证过的轻量接管、进房、状态读取和真实点击下注能力，用更少的刷新、更少的后台采集和更清晰的界面完成稳定对冲。

最高保护区域：余额、局号、状态机、倒计时、房间号、限红、坐标定位、下注前检查和真实点击执行链路。任何后续修改如果可能影响这些链路，必须先说明风险，再取得明确继续指令，并只做最小改动。

当前阶段优先目标：
- 让轻量 UI 的显示、计划、执行记录、盈亏统计与轻量核心数据一致。
- 不把旧 UI 的高频采集、重 worker 事件流和冗余刷新搬入轻量 UI。
- 新增统计和界面功能时，不改变已验证的下注点击、坐标识别、下注前检查和状态采集核心逻辑。

运行约束：
- a1/a2/a3/a4 均可作为参与账号。
- 支持有头主号和无头副号混合运行；不能要求全部无头才能执行。
- 持续对冲由“启动轻量控制 / 暂停 / 急停”控制，不再以有限轮测试作为主流程。
