# 需求文档：操作者端账号/仪表盘/H5 改版

## 简介

本次改版覆盖操作者端账号管理、创建策略、仪表盘、平台更新展示、导航精简与“我的”页面。目标是让页面更适合 H5 使用，同时把账号层与策略层的职责边界理顺。

## 术语表

- 操作者端：`frontend/src/pages/operator` 下的页面与其对应 API。
- 账号层：绑定账号、账号登录、赔率同步、账号状态展示。
- 策略层：创建策略、编辑策略、启动/暂停/停止、模拟与真实投注切换。
- JND：加拿大 28 体系，当前内部平台值为 `JND28WEB / JND282`。
- 网盘：操作者前端展示名，对应当前内部 `JND28WEB`。
- 2.0：操作者前端展示名，对应当前内部 `JND282`。

## 需求

### 需求 1：账号页文案与表单语义调整

操作者在账号页中不应再看到“博彩账号”这一组表述，而应看到更通用、面向业务的中文文案。

#### 验收标准

1. 页面主标题改为“账号管理”。
2. 按钮“绑定新账号”保留，但展开后的表单标题改为“绑定账号”。
3. “账户名”输入框提示改为“请输入账号”。
4. “平台类型”改为“游戏类型”。
5. 游戏类型只展示“加拿大28”“极速飞艇”两类业务名，不在账号绑定层区分“网盘 / 2.0”。

### 需求 2：账号层与策略层的平台选择边界调整

操作者在绑定账号时只选择游戏类型；在创建策略时才选择 JND 策略使用“网盘”还是“2.0”。

#### 验收标准

1. 绑定账号接口与前端表单不再要求操作者选择 `JND28WEB` 或 `JND282`。
2. 创建策略页中“盘口类型”只允许展示账号当前有效验证结果导出的 JND 平台选项；若当前仅有一个有效平台，则锁定为该值；若当前没有有效验证结果，则不得提交依赖该账号的 JND 策略。
3. 创建策略时不得再强制要求“策略平台类型必须等于账号平台类型”这一旧规则。
4. 同账号可运行的平台范围与阻断规则由上游 `account-strategy-platform-decoupling` 契约决定；本 spec 只消费上游返回的允许选项与提示状态，不自行重开平台裁决。

### 需求 3：创建策略表单整理

创建策略页需要简化并贴合真实投注流程。

#### 验收标准

1. “创建策略”标题下方无多余“博彩账号”说明。
2. 基础金额默认值为 `1` 元。
3. 创建阶段不再提供“模拟模式”开关。
4. 策略创建成功后，操作者可以在策略页中继续切换“模拟 / 真实投注”。
5. 表单不得再给出 `0.01` 元下注暗示。

### 需求 4：平台更新改为仪表盘弹窗

平台更新应继续展示，但不能占用独立标签页。

#### 验收标准

1. “平台更新”不再作为单独主标签页存在。
2. 仪表盘提供平台更新入口。
3. 平台更新以弹窗形式展示，可关闭。
4. 仪表盘仅保留轻量摘要，不被平台更新内容长期占位。

### 需求 5：仪表盘聚合开奖与告警

仪表盘需要成为操作者的主工作台，而不是只展示摘要数字。

#### 验收标准

1. 仪表盘展示最近 10 期开奖数据。
2. 仪表盘可直接看到告警信息，而不是只看到未读数量。
3. 当出现错误或严重告警时，仪表盘能直接承接查看动作。
4. 仪表盘中的单条告警支持操作者手动关闭，仅移除前端显示，不删除后端告警记录与日志留档。
5. 在保留原有余额、盈亏、运行策略、待结算信息的前提下，布局仍适配 H5。

### 需求 6：导航精简且不减功能

操作者端标签页需要从移动端视角重新编排，在不删业务能力的前提下减少主导航数量。

#### 验收标准

1. 目标主标签页数量不超过 4 个。
2. “策略”主标签页可移除，但“新增策略”“编辑策略”“策略列表”“回测入口”能力必须保留。
3. “回测”可并入策略域。
4. “告警”可并入仪表盘。
5. 从仪表盘可以直接进入“新增策略”。
6. 从账号页可以直接进入“去创建策略”。

### 需求 7：新增“我的”页面

操作者需要查看自己平台账号的剩余额度和有效期，并可自助修改平台登录密码。

#### 验收标准

1. 新增“我的”页面。
2. 页面显示当前平台账号到期时间。
3. 页面显示当前平台账号可绑定账号总量与剩余额度。
4. 页面支持修改当前登录的平台账号密码。
5. 修改的是平台登录账号密码，不是已绑定投注平台账号密码。

### 需求 8：H5 优先布局

本次改版必须从移动端优先设计，而不是桌面页简单压缩。

#### 验收标准

1. 底部导航、弹窗、列表卡片、表单输入与操作按钮需适配窄屏。
2. 关键动作按钮在移动端首屏可达。
3. 合并后的页面不可因为信息堆叠导致主要操作被遮挡。
4. 回归验证需覆盖移动端断点和桌面端断点。
