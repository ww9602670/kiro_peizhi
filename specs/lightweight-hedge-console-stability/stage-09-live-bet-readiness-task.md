- 四账号配置可读，账号、密码、代理和登录 URL 不串号。

- 余额显示正常，低余额剔除线设置合理。
- 可下注状态与 UI 参考倒计时可被人工识别。
- 本轮计划显示正常，计划账号不少于 3 个。
- 急停按钮可见，操作者知道如何暂停/停止。

必须测试：

- 启动 exe smoke test。
- 登录页打开和批量填写。
- 接管与进房。
- 启动轻量控制前状态复核。
- 至少 10 个发号周期观察。
- 执行记录、缺口、耗时、流水、盈亏观察。
- 出现异常时暂停/急停和原因记录。

## 11. 人工测试步骤和观察点

1. 启动 `LightweightHedgeConsole.exe`，记录 exe 路径和启动时间。
2. 检查 a1/a2/a3/a4 配置是否完整，尤其是登录 URL、账号、密码、代理。
3. 点击打开登录页和批量填写，确认页面不是 `about:blank`，账号没有串号。
4. 接管账号，确认 a2 为有头主号，a1/a3/a4 为副号且状态可见。
5. 选择目标房间，批量进房，确认所有参与账号进入同一房间。
6. 等待 UI 显示房间、局号、余额、可下注状态和参考倒计时。
7. 启动轻量控制前，确认金额范围、点击间隔、确认等待、低余额剔除线。
8. 点击启动轻量控制后，只观察，不手动干扰页面。
9. 每轮观察本轮计划、执行记录、实际下注金额、缺口、耗时、流水和盈亏。
10. 至少完成 10 个发号周期后暂停，记录是否通过。

重点观察：

- 计划是否在真实点击前出现。
- 执行账号是否只包含计划账号。
- 实际下注金额是否进入执行记录和流水累计。
- 缺口为 0 或有明确原因。
- 余额和盈亏方向是否符合真实下注结果。
- 局号停更、余额不足、掉回大厅、少于 3 个账号时是否停止或降级，而不是继续盲发。

## 12. 风险监测点

- UI 显示风险：房间、局号、余额、倒计时显示错误或不同步。
- 数据源过滤风险：大厅状态、旧房间、旧局号、局号停更账号被误纳入计划。
- 状态同步风险：计划显示和真实点击执行的轮次不一致。
- 倒计时风险：UI 参考倒计时不代表真实下注资格，真实执行仍以核心下注前检查为准。
- 房间/限红绑定风险：计划金额和目标房间限红不一致。
- 余额风险：余额不足账号未剔除，或余额变化没有进入盈亏观察。
- 坐标风险：点击位置异常、筹码选择异常、下注区异常时必须立即急停，不在阶段 9 现场改坐标。
- 自动回房风险：真实点击期间不得插入进房动作。
- 资源风险：exe 卡顿、浏览器进程异常膨胀、UI 无响应时停止观察。
- 操作风险：人工误点页面、切换房间、修改金额或重启账号会污染观察结果，必须单独记录。
